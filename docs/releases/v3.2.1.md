# Impulse Client v3.2.1

## English

Protocol v3 patch candidate, versionCode 24. Authentication rejects unsupported or weaker Argon2id parameters and bounds accepted work. Failed stream writes retain the encrypted outbox for retry. Stored history is decrypted only after signature and routing verification. A Room v5-to-v6 migration adds a persistent hashed nonce journal with atomic message admission; existing messages remain intact. Legacy envelopes without a nonce and pre-upgrade messages have explicitly documented replay limitations.

Incoming data, synchronization and key exchange now await processing in the transport reader. Unknown-key messages have bounded retention (128 total, 16 per sender, 8 MiB, 30 seconds). Supported x86_64 emulators can use the native QUIC transport; x86 has no native QUIC library. Biometric unlock survives rotation and is revoked on real background transitions. Labels describe the actual Dilithium3 implementation.

Verification and remaining operational limits are recorded in `docs/audit/2026-10-14-defense-readiness.md`. This is a research prototype. The relay sees external metadata; first-peer trust uses TOFU; transport-write success is not an end-to-end delivery acknowledgement. No certification, universal platform validation or high-assurance production readiness is claimed.

## Русский

Патч Protocol v3, versionCode 24. Проверяются нижние и верхние границы Argon2id; неподдерживаемые параметры отклоняются. Зашифрованная исходящая очередь сохраняется при неудачной записи. История проверяет подписи и параметры маршрутизации. Добавочная миграция Room v5 → v6 сохраняет сообщения и атомарно записывает хешированные nonce. Ограничения старых конвертов и сообщений до обновления описаны отдельно.

Последовательная обработка входящих кадров ограничивает накопление работы; очередь ожидания ключей ограничена 128 сообщениями, 16 на отправителя, 8 MiB и 30 секундами. QUIC работает на поддерживаемых x86_64 эмуляторах; x86 библиотека отсутствует. Биометрический доступ сохраняется при повороте и блокируется при уходе в фон. Подпись корректно обозначена как Dilithium3.

Проект остаётся исследовательским прототипом. Результаты и ограничения приведены в отдельном отчёте; производственная готовность и сертификация не заявляются.
